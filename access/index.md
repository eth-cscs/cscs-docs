# Connecting to Alps

This section covers how to access CSCS Alps systems and services. All methods share the same authentication foundation: a CSCS account, project membership, and multi-factor authentication.

> [!NOTE]
>
> **Prerequisites**
>
> Before using any access method you need:
>
> 1. A CSCS account that is part of a project with allocated resources — see [accounts and projects](<https://docs.cscs.ch/accounts/index.md#getting-and-managing-accounts> "Getting and Managing Accounts")
> 2. Multi-factor authentication (MFA) set up — required for all CSCS services — see [MFA](<https://docs.cscs.ch/access/mfa/index.md#multi-factor-authentication> "Multi Factor Authentication")

## Access methods

- **Multi-factor authentication**

  Required before using any CSCS service. Set up a TOTP authenticator and enroll your device.

  [MFA setup](<https://docs.cscs.ch/access/mfa/index.md#multi-factor-authentication> "Multi Factor Authentication")
- **SSH**

  Terminal access to Alps clusters using signed SSH keys via the Ela jump host.

  [SSH access](<https://docs.cscs.ch/access/ssh/index.md#using-ssh> "Using SSH")
- **Web portals**

  Browser-based access to CSCS services via Single Sign-On.

  [Web portals](<https://docs.cscs.ch/access/web/index.md#accessing-cscs-web-portals> "Accessing CSCS Web Portals")
- **FirecREST**

  FirecREST is a RESTful API for programmatically accessing High-Performance Computing resources.

  [FirecREST](<https://docs.cscs.ch/access/firecrest/index.md#firecrest>)
- **HPC Console**

  Web-based dashboard for job submission, monitoring, and file browsing.

  [HPC Console](<https://docs.cscs.ch/access/hpc-console/index.md#hpc-console_1>)
- **JupyterLab**

  JupyterLab is a feature-rich notebook authoring application and editing environment.

  [JupyterLab](<https://docs.cscs.ch/access/jupyterlab/index.md#jupyterlab>)
- **VS Code**

  How to connect VSCode IDE on your laptop with Alps.

  [VS Code](<https://docs.cscs.ch/access/vscode/index.md#connecting-with-vs-code> "Connecting with VS Code")
