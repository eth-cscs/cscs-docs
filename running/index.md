# Running Jobs

[Slurm](<https://docs.cscs.ch/running/slurm/index.md#slurm>) is used on CSCS systems to schedule jobs. For scheduling many small jobs (1 core or short time) we recommend [HyperQueue](<https://docs.cscs.ch/running/hyperqueue/index.md#hyperqueue>). The [job report tool](<https://docs.cscs.ch/running/jobreport/index.md#job-report> "Job report") can be used in Slurm jobs to collect reports on how well an application uses the system.
