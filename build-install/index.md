# Building and Installing Software

CSCS provides commonly used software and tools on Alps, however many use cases will require first installing software on a system before you can start working. Modern HPC applications and software stacks are often very complicated, and there is no one-size-fits-all method for building and installing them.

- [**Programming Environments**](<https://docs.cscs.ch/software/prgenv/index.md#programming-environments>)

  Programming environments are your first option if you want to install an application (and its dependencies) from source, or set up a Python/Julia environment.

  CSCS provides the following uenv:

  [prgenv-gnu](<https://docs.cscs.ch/software/prgenv/prgenv-gnu/index.md#prgenv-gnu>)

  [prgenv-nvfortran](<https://docs.cscs.ch/software/prgenv/prgenv-nvfortran/index.md#prgenv-nvfortran>)

  [linalg](<https://docs.cscs.ch/software/prgenv/linalg/index.md#linalg>)

  [julia](<https://docs.cscs.ch/software/prgenv/julia/index.md#julia>)

  And containers are used to deploy:

  [Alps Extended Images for ML](<https://docs.cscs.ch/software/alps-extended-images/index.md#alps-extended-images>)

  [Cray Programming Environment](<https://docs.cscs.ch/software/prgenv/cpe/index.md#cray-programming-environment-cpe> "Cray Programming Environment (CPE)")
