# Climate and Weather Software

Software for the climate research community is available on [Santis](<https://docs.cscs.ch/clusters/santis/index.md#santis>). The software is maintained in a collaboration between the climate community and CSCS.

- [**ICON**](<https://docs.cscs.ch/software/cw/icon/index.md#icon>)

  Modelling framework for weather, climate and environmental prediction.
- **Community Codes**

  CSCS provides some uenv and guides for users of community codes on Eiger:

  [WRF and CRYOWRF](<https://docs.cscs.ch/software/userapps/wrf/index.md#wrf>)

  [ESMF and CESM](<https://docs.cscs.ch/software/userapps/cesm/index.md#esmf-and-cesm>)
- [**Deployment**](<https://docs.cscs.ch/software/cw/deployment/index.md#climate-and-weather-software-deployment> "Climate and Weather Software Deployment")

  How to create and deploy uenv images on Santis and Balfrin.
