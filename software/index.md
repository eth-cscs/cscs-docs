# Applications and frameworks

This section documents the most widely-used applications and frameworks on Alps.

## Supported software

CSCS provides a catalogue of [**supported software**](<https://docs.cscs.ch/policies/support/index.md#officially-supported-applications> "Officially Supported Applications"): applications, frameworks and tools that CSCS provide and support on Alps. All other software can be installed by users as [user software](<https://docs.cscs.ch/policies/support/index.md#user-applications> "User Applications").

These pages provided documentation for all supported software, and installation guides for selected applications that are frequently requested, particularly if they are challenging to install.
