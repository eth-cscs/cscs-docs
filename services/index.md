# Services

- **CI/CD**

  Configure CI/CD on Alps for your GitHub, GitLab and Bitbucket projects.

  [CI/CD](<https://docs.cscs.ch/services/cicd/index.md#continuous-integration-continuous-deployment-cicd> "Continuous Integration / Continuous Deployment (CI/CD)")
- **Developer Portal**

  Enables CSCS users to create and manage subscriptions to an API.

  [Developer Portal](<https://docs.cscs.ch/services/devportal/index.md#developer-portal>)
- **Kubernetes**

  Kubernetes platform for automating deployment, scaling, and management of containerized applications.

  [Kubernetes](<https://docs.cscs.ch/services/kubernetes/index.md#kubernetes>)
- **Inference**

  Managed LLM models accessible through public API endpoints, and Kubernetes services for deploying custom ML services.

  [Inference](<https://docs.cscs.ch/services/inference/index.md#inference>)
